# TurtlePen 3D geometry implementation plan

**Goal:** Implement and test the recovered proposal's first prototype under Chuck's
2026-09-08 instruction, `implement and test`. Work inline and preserve concurrent edits.

**Architecture:** A dependency-free geometry scene/compiler under `src/core/geometry3d/`.
Spatial coordinates have explicit mm/cm/m/in units and right-handed Z-up axes, separate
from integer diagram quadrants and page z. Schema 5 persists an optional geometry scene;
schemas 1–4 migrate without changing diagram geometry. TPF v1 is a strict JSON interchange
format. Core owns mutations; CLI/MCP reuse them. Physical printing and public deployment
are outside this local implementation/test request.

**Alternatives assessed:** A general WASM CAD kernel adds distribution/runtime complexity;
an exclusively voxel-based implementation misses the source's curved-primitive requirement.
Choose analytic primitives and deterministic triangulation, with exact orthogonal box
booleans as the bounded first boolean implementation. Reject unsupported curved booleans
explicitly. STEP/3MF/OBJ/PLY, sweeps, bevels and general CAD remain later source possibilities.

## 1. Scene and mesh compiler

Create `math.js`, `mesh.js`, `primitives.js`, `scene.js`, `export.js`, and `index.js`
under `src/core/geometry3d/`. Their responsibilities are transforms, topology inspection,
primitive/orthogonal geometry, transactional scene editing, interchange, and facade.

Write `test/geometry3d.test.js` first and observe failure. Public API:
`createScene({name,units})`, `applyCommands(scene,commands)`, `compileScene(scene)`,
`inspectScene(scene)`, `serializeTpf(scene)`, `deserializeTpf(text)`, `exportScene(scene,format)`.

Implement boxes, cylinders, spheres, circle/polygon extrusion; simple concave polygon
triangulation; XYZ transforms and flat groups. Explicit segment counts control curved
tessellation. Union/subtraction/intersection accept axis-aligned boxes only. Detect open
edges, nonmanifold vertex fans, reversed/degenerate faces and overlapping part bounds.
Bound input sizes, coordinates, tessellation and generated meshes. Transactions validate
before committing and refuse malformed or unsupported geometry without mutation.

Run `node --test test/geometry3d.test.js`. Check analytical volume and transformed bounds,
deterministic bytes, malformed input, overlapping parts, boolean volume, topology and units.

## 2. Document, CLI and MCP integration

Add `geometry3d` to `core.OPERATIONS`; use ordinary persistence/history/plan wrappers.
Persist and validate the optional scene in document schema 5, migrate schemas 1–4.
Expose `geometry3d`, `inspect_geometry3d`, `export_geometry3d` through a small tool module.
Export returns inline base64 when no path is provided, so remote clients receive actual
bytes; local paths use the existing confinement and atomic write helpers.

Add CLI `geometry3d --recipe <json> --format tpf|stl|glb --out <path>` and import of existing
TPF or diagram inputs. A recipe supplies units/name plus the same command array as core.
Provide explicit conversion of selected diagram ink to a solid at declared units per
quadrant; snapshot source ink into the scene instead of silently following later edits.

Write integration tests before wiring: document round trip, old-schema migration,
plan rollback, real MCP creation/undo/reopen/export and CLI output. Extend the existing
all-tools endpoint scenario for the three new tools. Keep 2D behavior tests intact.

## 3. Independent exported-artifact validation

Generate retained TPF/STL/GLB examples: stacked-box union, curved robot assembly,
extruded drawing and recognizable castle. Prove concave profiles in analytic tests. Validate
binary STL structure; GLB glTF 2.0 headers/chunks/bounds, SI-meter conversion and Y-up
coordinate conversion against the Khronos specification. STL explicitly emits millimeters.

Use installed Blender in background mode to import STL and GLB, measure bounds/volume,
check edges and winding, and render a preview for inspection. Physical print success is
not inferred from digital topology. Keep slicer/physical-printer evidence explicitly absent.
